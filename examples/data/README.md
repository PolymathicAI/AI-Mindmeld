# Example data

`proteins.fasta` and `proteins.tsv` describe 32 proteins (sequences, names, keywords, lineage and one-sentence
captions) drawn from UniProtKB/Swiss-Prot entries (The UniProt Consortium, https://www.uniprot.org). UniProt's data
is distributed under the Creative Commons Attribution 4.0 International license (CC BY 4.0,
https://creativecommons.org/licenses/by/4.0/). The `split` column was assigned for the
[CPU training example](../guides/extending.md#6-train-a-connector-on-cpu). The project's Apache-2.0 license covers its code, not this data.
